# InternMatch – AI-Powered Internship Matching Platform

## 📌 About the Project

**InternMatch** is an AI-powered internship matching platform designed to help students discover internship opportunities that align with their skills, interests, qualifications, and career goals.

The platform provides internship search and filtering tools, AI-powered job matching, career information, and career development resources to make the internship search process more efficient and accessible.

This project was developed collaboratively by **Jia Earn and me**, combining web development and AI-powered features to create a more personalised internship search experience.

## ✨ Key Features

- **Home Page** – Provides an overview of the platform and its key features.
- **User Registration & Login** – Allows job seekers to access their accounts.
- **Internship Search** – Search and filter internships based on field, location, work mode, duration, and allowance.
- **AI Job Matching** – Helps users identify internship opportunities relevant to their profiles and job descriptions.
- **Career Information** – Provides career-related information to support students in exploring potential career paths.
- **Career Toolkit** – Offers resources to help users prepare for internships and develop their career readiness.
- **Theme Customisation** – Supports different visual themes for a more personalised user experience.
- **Employer Portal** – Provides a separate login interface for employers.
- **Employer Dashboard** – Allows employers to access the employer interface and manage internship-related information.

## 🛠️ Technologies Used

- **Frontend:** HTML, CSS, JavaScript
- **Backend:** Python, Flask
- **AI / Machine Learning:** Scikit-learn
- **Data Processing:** Pandas
- **Document Processing:** PyPDF
- **API Integration:** Flask-CORS

## 🎯 Problem It Solves

Students often struggle to identify internship opportunities that match their skills, academic backgrounds, and career interests. Searching across multiple platforms can be time-consuming and make it difficult to determine which opportunities are the best fit.

InternMatch aims to simplify this process by bringing internship discovery, AI-assisted job matching, and career preparation resources together in one platform.

## 💻 Getting Started

### 1. Clone the Repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
cd InternMatch
```

### 2. Create a Virtual Environment (Recommended)

```bash
python -m venv .venv
```

Activate the environment on Windows:

```bash
.venv\Scripts\activate
```

### 3. Install Dependencies

```bash
pip install -r requirements.txt
```

### 4. Run the Application

```bash
python backend.py
```

Follow the local URL displayed in the terminal to access the application, if the backend is configured to serve the frontend locally.
